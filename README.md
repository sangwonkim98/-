# 서울 지하철 프로젝트 자료

브라우저에서 [데이터 개괄 HTML](서울지하철_데이터개괄.html)을 열면 데이터별 구조, 원본 표본, 범위와 품질 점검 결과를 살펴볼 수 있습니다. 외부 라이브러리나 서버 설치 없이 동작합니다.

자세한 내용은 [원천데이터 조사](원천데이터_조사.md)를 확인하세요. 출처, 파일별 기간·컬럼, 과제 질문과의 연결, 확인한 품질 이슈를 정리했습니다.

```
raw/
  01_승하차/       2026년 상반기, 일별·시간대별·승객유형별 승하차
  02_열차혼잡도/   1~8호선 혼잡도 4개, 9호선 혼잡도 2개
  03_역좌표/       1~8호선 좌표 원본
  04_OD/           TOPIS 2026년 6월 ZIP, 지하철 CSV와 공식 설명서
metadata/          출처 페이지, 다운로드 이력·해시, 컬럼 사전, 품질 확인
scripts/           수집·구조 확인 코드와 의존성
서울지하철_데이터개괄.html
원천데이터_조사.md
```

원본의 값과 인코딩은 유지했습니다. 정제·집계·시각화 결과는 이후 별도 폴더에 생성하면 됩니다.

과제 제출물: 최종 보고서 10쪽 이상(국문/영문), 영문 발표 파일, 오류 없이 실행되는 코드. 안내된 마감은 11월 24일 23:59이며 팀장 1명이 Cyber Campus 팀 프로젝트 제출함에 제출합니다.
